# Contents Researcher - 테스트 계획 체크리스트

## 테스트 원칙 (workflow_test.txt 기반)
- 모든 E2E 테스트는 Playwright로 진행
- 더미데이터 사용 금지
- 하드코딩 금지
- 중복 구현 검출
- 오버스펙 검출
- 테스트 완료 후 종료되지 않은 테스터 프로세스 반드시 종료
- **주석 삭제 절대 금지**

- [ ] Comment 모델 CRUD 테스트
- [ ] KeywordTrend 모델 CRUD 테스트
- [ ] collection_jobs 모델 CRUD 테스트
- [ ] TimescaleDB 하이퍼테이블 정상 동작 확인
- [ ] 중복 body_hash 삽입 시 처리 확인

### 1.2 API 엔드포인트 테스트
- [ ] POST /api/v1/contents/search — 키워드 검색 정상 응답
- [ ] POST /api/v1/contents/search — 필터 조합 (출처 + 감성 + 날짜)
- [ ] POST /api/v1/contents/search — 빈 결과 응답
- [ ] POST /api/v1/contents/search — 페이지네이션 정확성
- [ ] GET /api/v1/contents/{id} — 존재하는 ID 상세 조회
- [ ] GET /api/v1/contents/{id} — 존재하지 않는 ID 404 응답
- [ ] GET /api/v1/contents/trending — 기간별 트렌드 조회
- [ ] GET /api/v1/keywords/top — 인기 키워드 목록
- [ ] GET /api/v1/keywords/trend — 키워드 시계열 데이터
- [ ] GET /api/v1/sources/stats — 출처별 통계
- [ ] POST /api/v1/crawler/trigger — 수집 트리거 정상 응답
- [ ] GET /api/v1/crawler/status — 수집 상태 조회
- [ ] GET /api/v1/scheduler/jobs — 스케줄 목록
- [ ] POST /api/v1/scheduler/jobs — 스케줄 추가
- [ ] DELETE /api/v1/scheduler/jobs/{id} — 스케줄 삭제

### 1.3 서비스 로직 테스트
- [ ] search_service — 복합 필터 쿼리 생성 정확성
- [ ] search_service — 정렬 옵션별 결과 순서

- [ ] trend_service — 기간별 집계 정확성

## 3. NLP 분석기 테스트 (pytest)

### 3.1 키워드 추출
- [ ] 한국어 텍스트에서 명사 추출 정확성
- [ ] 불용어 필터링 동작
- [ ] KeyBERT 상위 N개 키워드 반환
- [ ] 빈 텍스트 입력 시 빈 배열 반환
- [ ] 특수문자/HTML 태그 포함 텍스트 처리

### 3.2 감성 분석
- [ ] 긍정 텍스트 → "positive" 분류
- [ ] 부정 텍스트 → "negative" 분류
- [ ] 중립 텍스트 → "neutral" 분류
- [ ] 부정어(안, 못, 없) 극성 반전 동작
- [ ] 점수 범위 (-1.0 ~ 1.0) 확인
- [ ] 빈 텍스트 → "neutral" (0.0)
- [ ] 전략 패턴 전환 (dictionary ↔ model) 동작

### 3.3 중요도 산정
- [ ] 가중 합산 점수 계산 정확성
- [ ] 정규화 범위 (0.0 ~ 10.0) 확인
- [ ] 가중치 변경 시 점수 변화 확인
- [ ] 모든 값이 0인 컨텐츠 처리

### 3.4 분석 파이프라인 통합
- [ ] 수집된 ContentItem에 keywords 필드 채워지는지 확인
- [ ] 수집된 ContentItem에 sentiment/sentiment_score 채워지는지 확인
- [ ] 개별 댓글에 감성 분석 결과 적용 확인
- [ ] importance_score 계산 및 저장 확인

## 4. 프론트엔드 E2E 테스트 (Playwright)

### 4.1 공통
- [ ] 사이드바 네비게이션 — 모든 메뉴 클릭 시 올바른 페이지 이동
- [ ] 반응형 레이아웃 — 모바일/데스크탑 전환
- [ ] 로딩 상태 표시 확인

### 4.2 대시보드 (/dashboard)
- [ ] 페이지 로드 시 수집 현황 카드 표시
- [ ] 키워드 트렌드 차트 렌더링
- [ ] 최근 수집 컨텐츠 테이블 데이터 표시
- [ ] 수집 스케줄 상태 표시

### 4.3 컨텐츠 검색 (/contents)
- [ ] 검색어 입력 후 검색 실행 — 결과 표시
- [ ] 출처 필터 선택 — 해당 출처만 표시
- [ ] 감성 필터 선택 — 해당 감성만 표시
- [ ] 날짜 범위 필터 — 범위 내 결과만 표시
- [ ] 정렬 변경 — 결과 순서 변경 확인
- [ ] 페이지네이션 — 다음/이전 페이지 이동
- [ ] 검색 결과 카드 클릭 → /contents/[id] 이동

### 4.4 컨텐츠 상세 (/contents/[id])
- [ ] 컨텐츠 기본 정보 표시 (제목, 출처, 날짜)
- [ ] 원본 링크 클릭 가능
- [ ] 키워드 목록 표시
- [ ] 감성 분석 결과 표시 (긍정/부정/중립 비율)
- [ ] 댓글 목록 표시 + 개별 감성 라벨
- [ ] 뒤로가기 동작

### 4.5 키워드 트렌드 (/keywords)
- [ ] 인기 키워드 순위 표시
- [ ] 급상승 키워드 표시
- [ ] 트렌드 차트 렌더링
- [ ] 기간 필터 변경 시 차트 업데이트
- [ ] 출처 필터 변경 시 데이터 갱신

### 4.6 스케줄러 (/scheduler)
- [ ] 스케줄 목록 표시
- [ ] 스케줄 추가 → 목록에 반영
- [ ] 스케줄 수정 → 변경 사항 반영
- [ ] 스케줄 삭제 → 목록에서 제거
- [ ] 다음 실행 예정 시간 표시
